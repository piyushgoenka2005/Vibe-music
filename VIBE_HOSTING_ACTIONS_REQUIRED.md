# VIBE_HOSTING_ACTIONS_REQUIRED.md

Actions that cannot be completed from the repository alone (CloudOnFire / DNS / Google Cloud).

| Priority | Panel location                            | Exact setting                                    | Current value                  | Recommended value                                                       | Why                                                            | Expected impact             | Risk                                      | Rollback                              |
| -------- | ----------------------------------------- | ------------------------------------------------ | ------------------------------ | ----------------------------------------------------------------------- | -------------------------------------------------------------- | --------------------------- | ----------------------------------------- | ------------------------------------- |
| P0       | Google Cloud Console → OAuth client       | Authorized redirect URIs                         | Unknown without console access | `https://vibemusic.in/api/auth/callback/google` (+ www variant if used) | Google login fails with Configuration/Callback if URI mismatch | Reliable Google login       | Low                                       | Remove URI                            |
| P0       | Hosting env (cp.cloudonfire.com / `.env`) | `AUTH_ALLOW_DANGEROUS_EMAIL_LINKING`             | May be `false` or unset        | unset or `true`                                                         | Enables same-email Google↔password linking with adapter        | Fixes account-link dead-end | Medium (only link verified Google emails) | Set `false` + use password-first flow |
| P1       | CDN / nginx                               | Cache-Control for `/_next/static` and CDN images | Unknown                        | `public, max-age=31536000, immutable` for hashed assets                 | Faster repeat visits                                           | Lower LCP on warm cache     | Low                                       | Revert header                         |
| P1       | Node / process manager                    | Workers / RAM                                    | Unknown                        | Match CPU; avoid single overloaded worker                               | Admin + catalog concurrency                                    | Lower TTFB under load       | Medium                                    | Scale back                            |
| P2       | PostgreSQL                                | Connection pool size                             | Unknown                        | Align with Prisma `connection_limit`                                    | Prevents queueing                                              | Lower DB wait               | Medium                                    | Lower pool                            |

Code-side auth linking + catalogue fixes ship without these; production OAuth still needs correct redirect URI + env on the host.
