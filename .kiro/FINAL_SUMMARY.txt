Error Handling Strategy:
  Layer 1: seedCategoriesFromStatic() - Handle external failures
           Wraps getAllProducts() in try-catch, continues on failure
  
  Layer 2: listCategories() seed operation - Handle seed failures
           Falls back to staticCategories() if seed fails
  
  Layer 3: listCategories() database fallback - Handle DB failures
           Returns staticCategories() on any error
  
  Result: API ALWAYS returns valid categories, NEVER throws error

Cache Invalidation Strategy:
  - Uses expire: 0 (forces fresh data on next request)
  - Invalidates tags: "categories", "catalog", "homepage"
  - Revalidates paths: "/", "/category/[slug]", "/admin/homepage"
  - Purges NGINX edge cache
  - Publishes version beacon for cross-process sync
  - Timing: < 1 second roundtrip verified

Database Schema:
  - Categories table with parent-child support (parentId)
  - Cascading deletes for cleanup
  - Sort order support
  - Featured flag support
  - Image URL fields
  - Timestamps

Real-Time Sync:
  - Admin changes trigger cache invalidation
  - expire: 0 ensures no stale content
  - buildCategoryMegaMenus() regenerates navigation
  - Next page refresh gets fresh data
  - Typical timing: < 1 second
